# [`polyPlot`](https://github.com/cwendorf/polyPlot/)

## Introduction

Distribution summaries can be difficult to compare when measures of center and spread are viewed separately. `polyPlot` layers several summaries over a histogram or density curve so their relationships are visible together.

- [Overview](#overview)
- [Resources](#resources)

---

### Overview

Each plot brings together quartiles, split-half means, mean-and-standard-deviation bounds, and the range. `polyStats` returns the corresponding quartile, mean, z-score, and range summaries in a structured matrix.
